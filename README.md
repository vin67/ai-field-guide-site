# AI Field Guide for architects

Practical AI basics for architects in four short sessions: prompting, reusable skills, why AI gets it wrong, and grounding with RAG. Works with any AI assistant.

- **Open it in your browser:** https://vin67.github.io/ai-field-guide-site/
- **Download it for offline use:** [ai-field-guide.html](https://github.com/vin67/ai-field-guide-site/releases/latest/download/ai-field-guide.html) – one file that opens in any browser.

Your progress and notes are saved only in the browser you use, never sent anywhere.

This repository holds only the published guide. Version 5.0.5.
